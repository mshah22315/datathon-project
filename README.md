# Datathon Project

The goal of this project was to build a predictive model for first-year enrollments to a university based on varying factors. After feature selection and model comparison, the chosen model was a Gradient Boosting Regressor, with only a certain amount of features kept. There is a model script where the GBR model is run and predicted probabilities of enrollment are calculated, and then those probabilities and the predictors are stored. There is also a script for a Streamlit app where you can demo the model.
